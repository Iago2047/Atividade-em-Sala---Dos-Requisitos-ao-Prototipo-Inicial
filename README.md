# Protótipo de Sistema de Estacionamento

Protótipo em linha de comando para gerenciamento de vagas de estacionamento em campus universitário.

## Requisitos Cobertos
- **RF01**: Visualização de vagas disponíveis e verificação de setores lotados em tempo real.
- **RF02**: Identificação visual e bloqueio de seleção de vagas reservadas para funcionários por alunos.

## Como Executar
Garanta que possui o Python instalado e execute o ponto de entrada principal:
```bash
python main.py
